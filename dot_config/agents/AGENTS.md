# Global agent guidance

Follow YAGNI principles. Prefer the smallest clear solution. Avoid unnecessary abstractions.

## Sentry

- When diagnosing EmpowerSuite errors or regressions, use `sentry issue list newvue/empowersuite --period 7d --json` to inspect relevant Sentry issues.

## Version control

- The user uses GitLab.
- If asked to create or manage a merge request, prefer the `glab` CLI.
- When replying to merge request comments, reply to each comment thread individually instead of posting a single combined comment.
- When proposing a new branch name, prefer the `jpambrun/...` prefix unless the user asks otherwise.

## Writing style

- Use plain, natural language and active voice. Keep useful technical terms, but avoid jargon, hype, and stock AI phrases.
- Lead with the answer. Keep explanations concise, split dense sentences, and cut repetition and filler.
- Make concrete claims about what changed, how it works, or what the evidence shows. Name sources and state uncertainty when it matters.
- Write with a human voice. Vary sentence length, use "I" when natural, and give a reasoned opinion when it helps. Preserve the intended meaning and tone when editing.
- Avoid flattery, canned openings, and generic conclusions. State the point directly instead of using "not just X, but Y" framing.
- Do not use em dashes. Separate thoughts with periods or commas, without substituting parentheses, en dashes, or hyphens as dashes.
- Use sentence case headings and straight quotes. Avoid decorative emojis, excessive boldface, and forced lists.
- Use colons for lists or examples. Keep formatting simple and useful to the reader.
